Status: Resolved We can confirm this issue has now been resolved. Summary Between approximately 16:07 and 17:11 today, some Accurx Desktop users were unable to save messages to the medical record using "Save to Record." What happened A code change deployed earlier today caused desktop clients to fail when saving communications to patient records. The engineering team identified the root cause and rolled back the affected change.
