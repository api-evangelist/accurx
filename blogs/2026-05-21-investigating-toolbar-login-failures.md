Status: Resolved Summary of Impact: Some users experienced a "your login has failed" error message when attempting to log into the Accurx toolbar, which was preventing access to the desktop toolbar for some users. Resolution: The issue has now been resolved. A fix was implemented in the latest version of the Accurx toolbar and we have not identified any further reports following the rollout.
